# Aksoy City — notes for Claude

SimCity BuildIt-style grid city builder, played on iPhone 16 Pro Safari. Live: https://mustafaaksoy566.github.io/aksoy-city/ (repo mustafaaksoy566/aksoy-city, pushing to main deploys via .github/workflows).

## Working with the user
- Speak **Turkish**, simply, step by step. The user does not code. After every batch, list each request and what was done (they often say "hepsini yap, hiçbirini unutma").
- They usually ask "devam et daha fazlasını ekle": implement every listed item, then add something extra, test it, commit + push, and report in Turkish.
- Free/CC0 assets: download without asking ("daha fazla siteden yardım alman gerekiyosa al bana sorma"), report what you used afterwards. Ask before anything paid, any account, or any software install. Never create accounts, enter tokens/passwords, change system or security settings, or accept terms for them.
- Connection: kenney.nl / itch.io / opengameart only work with Cloudflare WARP on. github.com, poly.pizza (`https://static.poly.pizza/<uuid>.glb`), quaternius, polyhaven work. GitHub API gets rate-limited; verify deploys by fetching the live page and grepping for the new `index-*.js` bundle name.
- Raw downloaded packs live in `assets-raw/` (gitignored). The style is KayKit City Builder Bits (2x2 units, scale 0.5) + Kenney skyscrapers + procedural models.

## Dev and test
- Node: `"/c/Program Files/nodejs/node.exe"`. Dev server: `.claude/launch.json` (vite on port 5173, `--host`). Build check: `npx tsc --noEmit` then `npm run build`.
- The user may be playing in the browser pane. Test on a separate origin so their save (localStorage) is untouched: http://127.0.0.3:5173 (or .4/.5; open the demo via Ayarlar → Hazır şehir). Move the camera with `rig.target.set(...); rig.distance = d; rig.apply()`.
- Dev helper `window.__aksoy` (DEV only): `{renderer, scene, camera, rig, city(), weather, view, sky, highway, traffic, walkers, open, pick, refresh}`. Set `rig.bounds` to look outside the city.
- Synthetic pointer tests: send `pointercancel` for ids 0..29 first (stale ids block drags).
- After changing `city.ts`, always round-trip a save (`serialize` → `load`).

## Architecture (src/)
- `config.ts`: all constants and catalog (BUILD_GROUPS, TOOL_INFO, COST, UNLOCK, FOOTPRINT, DECOR, INDUSTRY, SHOPS, MAKER_LEVELS, RES_LEVELS 8 levels, ROAD_GRADES, TRAFFIC).
- Map: `SIZE=48` cols × `ROWS=64` rows (`NORTH=16` sea rows on the north). `idx = z*SIZE + x`; world pos = `(x - SIZE/2 + 0.5, z - Z0 + 0.5)`, `Z0=40`. Plots 8×8. Sea for `z < COAST_ROW` except the `ISLAND` ellipse; roads over sea = suspension bridges (`SEA_BRIDGE`). River columns `RIVER`, rows `RIVER_ROWS`.
- `city.ts`: game state, rules, traffic BFS (`updateTraffic`, `congestion`), road grades (`Tile.grade` 1 = Bulvar, 2 = Cadde with 4 lanes), `streetOf`/`upgradeStreet`, maker upgrades, save/load. Save is v5 with `rows`, `rg:2`, `o`. Load migrates old saves (z shift, com → res, refunds for trade and buildings on sea). Roads and rails on water are kept.
- `view.ts`: builds meshes per tile (static chunks merged by `batcher.ts`), road decorations (`roadExtras`, `junctionExtras`, `culDeSac`, `signalPost`), bridges (`suspension`), construction sites, ghost road preview (`showRoadPreview`), traffic overlay.
- `traffic.ts`: cars and buses (lanes, queueing, traffic lights, cul-de-sac U-turns, parking lots and garages, see below) and walkers (leave and enter house doors). `signals.ts`: traffic-light timing.
- `input.ts`: tile input; road and rail drawing follows the finger path (`follow`). `camera.ts`: custom rig (pan, pinch, twist, two-finger tilt, PC keys).
- `terrain.ts` (world outside and under the city, coast, island, river, highway tunnel), `water.ts`, `trees.ts` (procedural trees), `towers.ts` (procedural towers, villas, apartments: `proc/` paths), `historic.ts` (Eiffel, Liberty, Pisa, Galata, Colosseum, Pyramid, stadium), `landmarks.ts` (mosque, lighthouse, marina, zoo, clock tower, `makeDecor`), `highway.ts`, `rails.ts`/`trains.ts`, `sky.ts`/`planes.ts`, `daynight.ts`, `weather.ts`, `ui.ts`/`info.ts` (HUD, build catalog, info cards), `thumbs.ts` (menu pictures).
- Housing: RES_LEVELS has 3 models per level (cottage → family house → small apartment → midrise → towers, `houses.ts` + `towers.ts`); upgrading keeps `t.variant` so the colour family stays.
- Detailed procedural buildings (skyscraper quality): `utilities.ts` (makeUtility(kind, level) grows per level), `industry.ts`, `services.ts`, `fun.ts` (ferris wheel, funfair with coaster/carousel/drop tower/pirate ship, museum, fountain, statue, observatory, parks via makePark), `places.ts` (station, bus stop, metro(level), airport + RUNWAY, university, beach + palm, parkingGarage(level), tunnelThumb). Shared helpers/materials in `parts.ts`; text signs via `signs.ts` signMat (cached).
- `mergeStatic` returns a Group that keeps its own transform (models can return it directly); only the chunk groups in view.flush set matrixAutoUpdate=false. Animation hooks in userData (see view.ts needsLive): spin, smoke, blink, wheel, ship, carousel, drop, swing, spray, beam, bob, animals.
- Older module list: `houses.ts` (procedural houses), `towers.ts` (procedural skyscrapers + midrise apartments, HELIPADS registry), `cars.ts` (procedural cars, CarSet = paint/trim/lights instanced meshes with per-instance paint colour), `helicopters.ts` (fly between tower helipads), `ski.ts` (Aksoy Dağı ski resort: lodge, chairlift, skiers), `extras.ts` (lake, big lake, hill, beach volleyball, casino), `highway.ts` (4-lane motorway ribbons, roundabout at the city entrance, tunnel at HW.portal=-44, ski road; HighwayTraffic routes).
- Service map (main.ts renderServiceMap, view.showServiceMap, ui setServiceBar): tapping a utility/service building (or the ⚡/💧 HUD) whitens the city, coverage tiles green, covered houses green / uncovered red; arrows cycle categories.
- Move/rotate buildings: long-press (450 ms) or card "✋ Taşı" lifts a building; after dragging it waits with a ✓ / ✗ / ↻ bar (ui setPlaceBar). ✗ restores place and facing, ✓ commits via city.moveBuilding(from, x, z, facing). Card "↻ Döndür" rotates in place. Code: input.ts hold/grab → main startMove/confirmMove/cancelMove/rotateMove, view.startMove/moveLifted/turnLifted/endMove.
- Parking lots upgrade to 2-5 storey garages (PARKING_LEVELS); upgraded lots act as garages in traffic.
- Metro: city.metro (Uint8Array tunnels, saved as `m`), tool `tunnel` drawn like roads, Metro button toggles the underground view (metro.ts MetroView: veil, street ghosts, coloured lines, station rings, trains). A line is active when it links ≥2 metro stations; active stations get bigger radius/happiness/transit (METRO_LINE), stations upgrade via METRO_LEVELS.
- Highway: roundabout at the city entrance; south-west of the city a cloverleaf (HW.clover): N-S motorway on the ground, E-W motorway (HW.west → HW.east) on a bridge (bHeight), loops + outer ramps from cloverQuadrant(k); route parts carry per-point heights (Lane.hs).
- City entrance: tiles x=-1,-2 outside the map are drawn with view.entranceTile (same as city roads) in main.syncHighway; highway gate routes exist per city lane (HighwayTraffic.setCityLanes ← traffic.entranceLanes), handoff is position- and lane-continuous; leaving cars wait at the edge if highway.canLeave() is false; cars on tile 0 heading west always exit (no U-turn); buses come from/return to the highway (sendBus, type -1 drawn by HighwayTraffic.busMesh).
- Junction signals: one pole per approach (view signalPost(tile, mask)) with red/amber/green (signals.ts SIGNAL_MATS.amber); street lamps are procedural (view streetLight).
- Traffic (traffic.ts): cars never spawn mid-road. Junction right-of-way: a car stops at STOP if a conflicting movement (conflicts()) is inside/committed in the junction, if its exit has no room (don't block the box) or a conflicting car has waited longer on green; one manoeuvre per parking lot at a time; long-stuck cars fade out (vanish) instead of driving through others. Cadde lanes WIDE_LANES [0.125, 0.3]. They leave parking lots (a walker walks from a nearby house first), tower garages, service stations (ambulance/fire/police) or enter from the motorway at the city entrance; they route (BFS distance fields) to a lot, a garage or the exit. Look-ahead boxes stop cars/walkers from overlapping.
- Roads use a recoloured copy of the KayKit atlas (assets.ts ROAD_COLORS, SimCity-like navy asphalt). Dead ends are drawn by culDeSac() in view.ts (half road + rounded end).
- Reference screenshots from the user live in `ÖRNEK/` (git-ignored, SimCity BuildIt). Use them for look and feature ideas only.
- Demo city: Ayarlar → "Hazır şehri aç" loads public/ornek-sehir.txt (gzip+base64 save); the player's own city is backed up to the -kendi key. To refresh the file from the 127.0.0.3 tab, gzip+base64 the save in the page and POST it to /__hazir-sehir (dev-only Vite plugin in vite.config.ts).
- Testing with a large city: the 127.0.0.3 tab holds a showcase city (~500 houses); keep power/water supply >= demand there.
- Code comments are in Turkish. Match that.
